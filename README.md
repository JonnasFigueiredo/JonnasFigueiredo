## Sobre mim

Trabalho com tecnologia desde 2018 e hoje atuo como QA Automation Engineer (SDET). Meu maior domínio é em Java e Selenium, mas o que me move mesmo é entender o negócio por trás do sistema. No fim, é isso que faz um teste valer alguma coisa.

Trabalho com testes de aplicações web, mobile, API e backend. Além de Java e Selenium, mexo bastante com Appium e TypeScript, montando e mantendo a automação que dá segurança pra entregar sem regressão.

Também gosto de compartilhar o que aprendo: faço palestras sobre qualidade e automação de testes.

Contribuo com projetos open source quando encontro algo que dá pra melhorar. No [moto](https://github.com/getmoto/moto/pulls?q=is%3Apr+author%3AJonnasFigueiredo+is%3Amerged) implementei três APIs da AWS que faltavam: upload de camadas no ECR, atributos de serviço no Cloud Map e `UpdatePipe` no EventBridge Pipes. No [Pillow](https://github.com/python-pillow/Pillow/pull/9906) corrigi um heap-buffer-overflow no `BoxBlur`. No [testcontainers](https://github.com/search?q=org%3Atestcontainers+is%3Apr+author%3AJonnasFigueiredo+is%3Amerged&type=pullrequests) escrevi dois módulos novos, Toxiproxy em Python e InfluxDB em TypeScript. No JUnit, escrevi a [seção da documentação sobre instâncias e estado de extensões](https://github.com/junit-team/junit-framework/pull/6010).

## Projetos

- **[Proteu QA](https://github.com/JonnasFigueiredo/proteu)** · [Chrome Web Store](https://chromewebstore.google.com/detail/proteu-qa/edpjppimngkekieldgokejdccfpiehgn): extensão para QAs que gera dados de teste realistas de 12 países e transforma elementos da tela em código pronto para automação, sem enviar nada para fora do navegador.
- **[Hefesto](https://github.com/JonnasFigueiredo/hefesto)**: plataforma com IA para QA e PO. A partir de um requisito, ou até de um print da tela, escreve a história no Jira, avalia se ela está pronta para desenvolvimento, cria os casos de teste e mostra o que ficou sem cobertura. Também funciona direto pelo chat de assistentes de IA e com modelos que rodam no próprio computador.
- **[Hermes](https://github.com/JonnasFigueiredo/Hermes)**: framework de automação de testes E2E mobile com Appium, Java e Cucumber. Os mesmos cenários, escritos em português, rodam em Android e iOS sem duplicar código: só os seletores mudam de uma plataforma para outra, e o alvo (emulador local ou grade de emuladores em Docker) é escolhido por configuração. No GitHub Actions, a suíte roda em uma matriz de emuladores Android e em simulador iOS, com [relatório Allure publicado](https://jonnasfigueiredo.github.io/Hermes/).

## About me

I have worked in tech since 2018 and today I am a QA Automation Engineer (SDET). My strongest ground is Java and Selenium, but what actually drives me is understanding the business behind the system. In the end, that is what makes a test worth anything.

I test web, mobile, API and backend applications. Besides Java and Selenium, I work a lot with Appium and TypeScript, building and maintaining the automation that makes it safe to ship without regressions.

I also like sharing what I learn: I give talks about quality and test automation.

I contribute to open source whenever I find something worth improving. In [moto](https://github.com/getmoto/moto/pulls?q=is%3Apr+author%3AJonnasFigueiredo+is%3Amerged) I implemented three missing AWS APIs: ECR layer upload, Cloud Map service attributes and `UpdatePipe` in EventBridge Pipes. In [Pillow](https://github.com/python-pillow/Pillow/pull/9906) I fixed a heap-buffer-overflow in `BoxBlur`. In [testcontainers](https://github.com/search?q=org%3Atestcontainers+is%3Apr+author%3AJonnasFigueiredo+is%3Amerged&type=pullrequests) I wrote two new modules, Toxiproxy in Python and InfluxDB in TypeScript. In JUnit, I wrote the [documentation section on extension instances and state](https://github.com/junit-team/junit-framework/pull/6010).

## Projects

- **[Proteu QA](https://github.com/JonnasFigueiredo/proteu)** · [Chrome Web Store](https://chromewebstore.google.com/detail/proteu-qa/edpjppimngkekieldgokejdccfpiehgn): an extension for QAs that generates realistic test data for 12 countries and turns on-screen elements into automation-ready code, without sending anything outside the browser.
- **[Hefesto](https://github.com/JonnasFigueiredo/hefesto)**: an AI platform for QA and PO. From a requirement, or even a screenshot, it writes the story in Jira, assesses whether it is ready for development, creates the test cases and shows what was left uncovered. It also works straight from AI assistant chats and with models running on your own machine.
- **[Hermes](https://github.com/JonnasFigueiredo/Hermes)**: a mobile E2E test automation framework with Appium, Java and Cucumber. The same scenarios, written in Portuguese, run on Android and iOS without duplicated code: only the selectors change between platforms, and the target (local emulator or a grid of emulators in Docker) is picked by configuration. On GitHub Actions the suite runs across a matrix of Android emulators and an iOS simulator, with a [published Allure report](https://jonnasfigueiredo.github.io/Hermes/).
